## To Update
Edit files directly on GitHub or clone locally.

## To Add Real Testimonials
Find the `testimonials-grid` section in `index.html` and replace placeholder cards.

## To Add YouTube Link
Search for `youtube.com` in `index.html` and replace with your real channel URL.

## To Add Contact Form Backend
Replace the `setTimeout` in `script.js` with a real Formspree or EmailJS call.
Free option: https://formspree.io — paste your endpoint URL.
